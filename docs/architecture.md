# System Architecture

The project is organized into the following components:

- **fl_logic/**: Core Federated Learning modules (Model, Client, Simulator).
- **federated_survival.py**: Standalone Python script for local federated simulation.
- **survival_federated.ipynb**: Interactive notebook for Google Colab/local simulation.
- **frontend/**: Vite-based web dashboard for result visualization.
- **docs/**: Technical documentation and literature reviews.

This structure is designed for simplicity and direct execution both locally and in the cloud.
