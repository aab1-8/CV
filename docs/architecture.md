# System Architecture

The project is organized into the following components:

- **federated_survival.py**: Standalone Python script containing the core Federated Learning engine (Models, Clients, and Simulation logic).
- **survival_federated.ipynb**: Interactive notebook for Google Colab/local simulation (synchronized with the standalone script).
- **frontend/**: Vite-based web dashboard for result visualization.
- **docs/**: Technical documentation and literature reviews.

This structure is designed for simplicity and direct execution both locally and in the cloud.
